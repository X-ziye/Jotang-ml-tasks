# Jotang 机器学习 Task 0 笔记

## 一、Task 1 入门概念与数学基础

### 1. 人工智能、机器学习与深度学习之间有什么关系？
他们是包含关系，深度学习是机器学习的方式之一，机器学习是人工智能实现的方法之一。
- 人工智能是终极目标（让机器表现出智能）。
- 机器学习是要从数据和例子中自己总结学习。
- 深度学习是利用神经网络来实现机器学习的一种具体技术路径。
### 2. 监督学习和无监督学习有什么区别？请各举一个例子
区别在于学习时有没有“参考答案”。
*例子*
- 监督学习：分类时给你类别，只需对号入座。
- 无监督学习：分类时什么都不给，直接按照各自特性分类，这里叫聚类。
### 3. 数据、特征和标签分别是什么？训练集、验证集和测试集各有什么用途？
- 数据：整个数据集，即机器学习时给机器的所有学习资料
- 特征（X）：描述数据里面每一个样本的所包含的各个属性
- 标签（Y）：数据里每一个样本的特征的目标变量（标准答案）

*数据集划分*
- 训练集：最先给机器用来学习的数据
- 验证集：训练集学习完后，用该数据进行调试，选最优方案
- 测试集：用来测试机器的真实水平
### 4. batch size 是什么？有什么影响？

batch size（批次大小）：即模型每次处理数据的多少

*影响*
- 学习稳定性，太小，每次学习的类别和方向差的太远，大一点会相对平稳真实
- 学习速率，太小速度慢，太大速率加快
- 内存占用，越大越占内存，物理限制下不能过大

### 5. 什么是模型和模型参数？
- 模型：从数据中学习得到的数学函数，比如 y = wx + b。
- 模型参数：函数里除自变量和因变量之外的未知数 w 和 b，靠数据训练得到，训练完成后通常不会改变。

### 6. 神经网络由哪些基本部分组成？什么是激活函数？为什么要激活函数？请介绍几种常见的激活函数
**基本组成：**
- 神经元（节点）：一个小计算单元。先把输入加权求和，再加上偏置，再经过激活函数。
- 层：
  - 输入层：接收特征（面积、像素等），通常不算“在学习的层”。
  - 隐藏层：中间那些层，负责把特征一层层加工。
  - 输出层：给出最终猜测（猫/狗，或房价）。
- 参数：层与层之间的 权重 w 和每个神经元的 偏置 b。训练就是在改这些数。
- 激活函数：每个神经元算完加权和之后，再套上的一个非线性变换。(w1·x1 + w2·x2 + … + b)
**为什么必须有激活函数？**
多层如果全是 wx + b 这种直线变换，叠多少层都还是一条直线（几层线性可以合成一层线性）。而现实问题几乎都是弯的，激活函数引入非线性，深层网络才有意义。

| 激活函数 | 数学公式 | 输出范围 | 导数（梯度） | 数学本质与优缺点 | 常见应用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Sigmoid** | 1 / (1 + e^(-x)) | (0, 1) | f(x) * (1 - f(x)) | 本质：把实数压缩到概率区间。<br>优点：平滑、可导，输出可解释为概率。<br>缺点：容易梯度消失（x极大/极小时导数趋近0）；输出非零中心。 | 二分类输出层 |
| **Tanh** | (e^x - e^(-x)) / (e^x + e^(-x)) | (-1, 1) | 1 - f(x)^2 | 本质：把实数压缩到零中心区间。<br>优点：零中心（比 Sigmoid 好），收敛更快。<br>缺点：依然存在梯度消失问题。 | 早期的隐藏层 |
| **ReLU** | max(0, x) | [0, +无穷) | x>0 时导数为1，x<=0 时导数为0 | 本质：单侧抑制、稀疏激活。<br>优点：计算极快；正区间梯度恒为1，缓解梯度消失。<br>缺点：存在“死亡 ReLU”问题（负区间梯度为0，神经元可能永远不更新）。 | 现代深度网络的标配隐藏层 |
| **Leaky ReLU** | max(0.01x, x) | (-无穷, +无穷) | x>0 时导数为1，x<=0 时导数为0.01 | 本质：给负区间留一个小斜率。<br>优点：解决了 ReLU 的“死亡”问题。<br>缺点：需要额外调超参数。 | 替代 ReLU 的隐藏层 |
| **Softmax** | e^(x_i) / sum(e^(x_j)) | (0, 1)，且和为1 | 雅可比矩阵（非逐元素求导） | 本质：把一组实数变成概率分布。<br>优点：输出是概率，多分类任务必备。<br>缺点：计算涉及指数，数值容易不稳定。 | 多分类输出层 |

### 7. 矩阵如何求导？提前学习该部分数学
核心原则：对谁求导，结果就和谁形状相同。损失 L 是一个数，参数 W 是矩阵，则 ∂L/∂W 和 W 一样大。深度学习里梯度与参数同形状（和 PyTorch 的 .grad 一致）。

*从标量到矩阵（理解）*
- 标量：y = 3x² → dy/dx = 6x，还是一个数。
- 向量：y 对向量 x 求导，得到和 x 一样长的梯度，每个分量是一个偏导。
- 矩阵：把矩阵里每个数都求偏导，再摆回原形状。实现时不把雅可比展开成超大张量，而是用形状刚好对上的矩阵乘法一次算完。

*最常用公式（L 为标量，A 为矩阵，x、a 为向量）*
- L = aᵀx  ⇒  ∂L/∂x = a
- L = xᵀx  ⇒  ∂L/∂x = 2x
- Y = AX，已知 ∂L/∂Y  ⇒  ∂L/∂X = Aᵀ (∂L/∂Y)
- Y = XA，已知 ∂L/∂Y  ⇒  ∂L/∂X = (∂L/∂Y) Aᵀ
- 加法 Y = U+V：两边梯度都等于 ∂L/∂Y（按各自形状广播）
- 逐元素激活 Y = σ(Z)  ⇒  ∂L/∂Z = (∂L/∂Y) ⊙ σ'(Z)（⊙ 是对应位置相乘）

*全连接层会用到的三条（Y = XW + b）*
设已经从后面传来 δ = ∂L/∂Y（和 Y 同形状）：
- ∂L/∂W = Xᵀ δ
- ∂L/∂X = δ Wᵀ
- ∂L/∂b = 把 δ 按样本那一维加起来

推导直觉：前向是“左乘输入、右乘权重”；反向要把误差传回去，所以多一次转置再乘。维度必须对上：X 为 n×d，W 为 d×h，Y 为 n×h，则 Xᵀδ 为 d×h，与 W 相同。

*链式法则*
和中学一样，中间变量可以是矩阵：∂L/∂W = (∂L/∂Y) 与 (∂Y/∂W) 按上面规则组合。反向传播就是一层层用链式法则把梯度传回去。

### 8. 怎么用矩阵乘法表示神经网络的全连接层前向传播过程？

全连接层的前向传播，数学上就是一次矩阵乘法，再加一个偏置：
**Z = XW + b**

#### 维度对齐（重点）
假设一个批次有 N 个样本，每个样本有 D_in 个特征：
- **输入 X**：形状为 (N, D_in)。（例如：3个样本，每个4个特征，X 就是 3 x 4）
- **权重 W**：形状为 (D_in, D_out)。（我们要把4个特征映射到2个神经元，W 就是 4 x 2）
- **偏置 b**：形状为 (1, D_out)。（每个神经元一个偏置，2个神经元，b 就是 1 x 2）

**矩阵乘法：**
(N, D_in) × (D_in, D_out) = (N, D_out)
然后加上 b (1, D_out)，Python 会自动广播成 (N, D_out) 再相加。
**最终输出 Z 的形状为 (N, D_out)。**

#### 物理意义（数学本质）
- 输出的 **N** 不变，代表还是这 N 个样本。
- 输出的 **D_out** 代表每个样本从原来的 D_in 维空间，被线性变换到了 D_out 维空间。
- 每一行代表一个样本，每一列代表该样本在某个神经元上的输出值。

#### 加上激活函数
得到 Z 之后，把 Z 里每个数字套上激活函数 f（如 ReLU）：
**A = f(Z)**
因为激活函数是逐元素（element-wise）操作，所以 **A 的形状仍然是 (N, D_out)**。

#### 为什么不是 WX？
在机器学习里，数据矩阵的约定是：**行代表样本，列代表特征**。
如果写成 WX，维度就是 (D_in, D_out) × (N, D_in)，直接报错。所以必须按 XW 的顺序来乘。

### 9. 前向传播与反向传播分别在做什么？损失函数、梯度和学习率在训练过程中扮演什么角色？

训练一轮可以想成：先往前猜，再往后改。

#### 前向传播
拿当前参数算出预测。数据从输入走进来，一层层做 Z = XW + b，再过激活函数，直到输出 \(\hat{y}\)。全程只计算，不改参数。

#### 反向传播
从对错出发，算出每个参数该怎么改。把 \(\hat{y}\) 和标签 y 比较得到损失 L，再用链式法则从输出层往回传，得到 ∂L/∂W、∂L/∂b。全连接层就是第 7 点里的 Xᵀδ、δWᵀ。

#### 损失函数、梯度、学习率各自干什么
- **损失函数**：打分器，衡量猜得有多差。回归常用均方误差，分类常用交叉熵。L 越小越好。
- **梯度**：指路牌，∂L/∂W 和 W 同形状。某个位置为正，表示这个参数变大损失也变大，所以要把它减小。
- **学习率 η**：步子大小。更新公式：W ← W − η · (∂L/∂W)。太大容易走过头，太小学得很慢。学习率是超参数，要自己定。

#### 串起来的一次更新
1. 前向：X → \(\hat{y}\)
2. 损失：比较 \(\hat{y}\) 和 y，得到 L
3. 反向：从 L 往回算梯度
4. 更新：参数减去「学习率 × 梯度」

然后换下一批数据（一个 batch）再重复。一句话：前向负责猜，损失负责打分，反向负责指出改谁，学习率负责改多狠。

### 10. 优化器是什么？有哪些？
优化器是拿梯度去改参数的规则。最简单就是 W ← W − η·(∂L/∂W)；复杂一点的会调步长、记住历史梯度，让训练更稳更快。
- SGD：每个 batch 算梯度再更新，最朴素；常加 Momentum（动量），少晃一点
- RMSProp / AdaGrad：按每个参数自己的历史，自动放大或缩小步长
- Adam：动量 + 自适应学习率，入门最常用（PyTorch 里 `torch.optim.Adam`）

SGD 是原型，作业里一般用 Adam。学习率还是要设的。

### 11. 什么是过拟合，欠拟合，正则化？
- 欠拟合：太简单或练不够，训练集和验证集都差（作业考试都差）
- 过拟合：把训练集甚至噪音都背下来了，训练很好、换新数据就差（作业满分期末砸了）
- 正则化：限制模型别学太死，减轻过拟合。常见是在损失上加惩罚：L_总 = L_原来 + λ·R(W)
  - L2（权重衰减）：惩罚参数平方和，让 w 变小、更平滑
  - L1：惩罚绝对值，容易让一些 w 变成 0
  - 另外还有 Dropout、早停、数据增强

λ 越大罚得越狠；太大又会欠拟合。一句话：欠拟合是没学会，过拟合是学太死，正则化是防止学太死。

## 三、Task 3 环境搭建笔记

### 1. 为什么不同项目最好使用不同的 Python 虚拟环境？
因为不同项目所需的Python环境可能不同，如果共用相同环境可能会有一个项目跑不起来，另外共用一个环境，项目间还可能起冲突。使用不同的Python虚拟环境可以将不同项目隔离开来，以确保代码的可复现性。同时这样也更方便程序员对项目进行维护。
### 2. CPU 和 GPU 各自擅长什么？训练神经网络为什么经常使用 GPU？
- cpu擅长逻辑控制、串行计算（按顺序一步步算），核心少但单核能力强。
- 擅长并行计算，核心极多（几千个），适合处理“同一时间做大量相同运算”的任务。
- 为什么用 GPU 训练：神经网络的核心是矩阵乘法Z=XW+b。矩阵里的每一个数字都需要进行相同的乘加运算，这正是 GPU 的强项（并行计算）。用 GPU 跑，速度比 CPU 快几十倍甚至上百倍。
### 3. CUDA 是什么？它、显卡驱动与 PyTorch 之间大致是什么关系？
1. **显卡驱动（GPU Driver）**
操作系统和显卡硬件之间的底层桥梁。
没有驱动，电脑识别不到显卡，显卡什么活都干不了。

> 
> 作用：告诉系统怎么操控 GPU 硬件。

2. **CUDA（Compute Unified Device Architecture，统一计算设备架构）**
NVIDIA 推出的**GPU 并行计算平台 + 编程模型**，**只有 NVIDIA 显卡能用 CUDA，AMD 显卡不行**。
CUDA 不是驱动！它是一套**开发工具包（CUDA Toolkit）**，提供库、编译器（nvcc），让代码可以在 GPU 上跑大规模并行运算。
3. **PyTorch**  
PyTorch 是**基于 Python 的开源深度学习框架**，由 Meta（原 Facebook）开发。
用来搭建、训练、运行神经网络，做 AI 模型（图像识别、大模型等）。
PyTorch 本身默认跑在 CPU；**当检测到 CUDA 可用时，就自动把张量、模型放到 GPU 加速计算**。
PyTorch 最基础的数据单元叫**Tensor（张量）**，可以理解为多维数组：

- 0 维：数字（标量）
- 1 维：一维数组（向量）
- 2 维：矩阵
- 更高维：图像、视频数据

张量**可以放在 CPU 上，也可以迁移到 NVIDIA 的 GPU 上**，放到 GPU 就会借助 CUDA 并行加速。

4. 关系

硬件（GPU） ➡️ 驱动（Driver） ➡️ CUDA（翻译官） ➡️ PyTorch（框架）
驱动管理显卡硬件，CUDA 提供 GPU 并行计算接口，PyTorch 调用 CUDA 实现 AI 运算 GPU 加速。如果底层缺了任何一环，PyTorch 就会退回使用 CPU。
