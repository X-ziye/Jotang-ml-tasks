# Task 1: 简单神经网络 (MLP) 实验报告

## 1. 数据集与任务
使用 `make_moons` 生成二分类数据，线性不可分，因此必须使用带激活函数的 MLP。

## 2. 实验设置
- 数据划分：6:2:2 (训练/验证/测试)
- 优化器：Adam，学习率 0.01
- 损失函数：BCE Loss (二分类交叉熵)
- 激活函数：ReLU (隐藏层)，Sigmoid (输出层)

## 3. 运行方法
1. 激活虚拟环境：`conda activate jotang`（或在终端使用 `conda run -n jotang python task1.py`）
2. 修改 `task1.py` 顶部的 `hidden_size` 变量（可选值：2、16、128）进行对照实验。
3. 运行代码：`python task1.py`
4. 运行后会自动生成对应的 Loss 曲线图、决策边界图和混淆矩阵图。

## 4. 对照实验：隐藏层宽度的影响
我分别测试了隐藏层大小为 2、16、128 的情况。

| 隐藏层宽度 | 测试集准确率 | 决策边界形状 | Loss 曲线 | 结论 |
| :--- | :--- | :--- | :--- | :--- |
| 2 | ~83.5% | 近乎直线 | 最终 ~0.30 | **欠拟合**：参数太少，学不会非线性特征 |
| 16 | ~89% | 有折角的曲线 | 最终 ~0.23 | **良好拟合**：性价比最高，泛化好 |
| 128 | 100% | 极其平滑复杂 | 最终 ~0.20 | **潜在过拟合**：参数是数据特征的几十倍，容易死记硬背 |

## 5. 思考题回答（趁热打铁）

- **为什么选择 ReLU 和 Sigmoid？**
  ReLU 首先引入非线性变换，若没有非线性激活，多层网络等价于单层线性模型，无法拟合 make_moons 这种线性不可分数据；其次该函数在正区间梯度为1，能有效缓解梯度消失，适合隐藏层。
  Sigmoid 可以将输出压缩到 (0,1)，把输出解释为样本属于正类的概率，适配二分类任务，也能与 BCE 损失搭配使用。

- **你选择了什么损失函数？为什么？那如果这一题是三分类问题呢？**
  选择 BCE Loss（二分类交叉熵），因为它基于极大似然估计推导，能衡量预测概率分布与真实标签分布的差异，配合 Sigmoid 使用。
  **如果三分类**：需要使用 `CrossEntropyLoss`（内部结合了 Softmax 和 NLLLoss），因为多分类输出需要先经过 Softmax 变成概率分布，再计算交叉熵。
  - **Softmax（激活函数）**：把一组原始输出 logits 转化为总和为 1 的概率分布，适用于互斥多分类。
  - **NLLLoss（损失函数）**：负对数似然损失，输入为概率的对数，只对真实类别对应的预测概率计算损失。 
  - **CrossEntropyLoss（损失函数）**：PyTorch 中等价于**Softmax + NLLLoss**的组合，内部自动完成 Softmax 激活与 NLLLoss 损失计算，用于互斥多分类，代码中不需要手动添加 Softmax 层。

- **optimizer.zero_grad()、loss.backward() 和 optimizer.step() 分别完成了什么工作？如果不清空梯度会发生什么？**
  - `optimizer.zero_grad()`：清空上一轮迭代遗留的梯度，防止梯度累加干扰本次计算。
  - `loss.backward()`：反向传播，自动计算损失函数对网络所有权重、偏置的梯度。
  - `optimizer.step()`：优化器根据计算得到的梯度，沿着梯度反方向（即损失下降方向）更新参数 w 和 b，以缩小误差。（更新公式：\(w_{new} = w_{old} - \eta \cdot \frac{\partial loss}{\partial w}\)）
  - **不清空梯度**：PyTorch 默认梯度是累加的。不清空会导致梯度越积越大，更新方向完全混乱，模型无法收敛。

- **更深、更宽的神经网络一定能取得更好的效果吗？模型过于简单或过于复杂分别可能带来什么问题？**
  不是。网络宽度不足时参数容量有限，会发生欠拟合（如隐藏层宽度 H=2），无法学习数据的非线性模式；宽度过大时模型参数量暴增，模型记忆训练集噪声，带来过拟合风险（如 H=128），同时增大计算开销。模型容量需要和数据复杂度匹配，寻找泛化能力与拟合能力的平衡点。

- **学习率过大或过小会怎样影响模型训练？你能从 loss 曲线中观察到哪些现象？**
  学习率过大：参数更新步长太大，Loss 曲线会剧烈震荡，甚至发散（越来越大），无法收敛。
  学习率过小：参数更新很慢，Loss 曲线下降极其平缓，训练需要极多轮次，容易陷入局部最优解。

- **假设还有一个分类问题，但是两个类别的样本数量非常不均衡，训练出来的模型会怎么样？为什么？说明了什么？**
  模型会倾向于预测多数类。因为只要全部猜多数类，准确率依然很高（比如 99%），但少数类几乎全被错判。这说明**准确率（Accuracy）在不均衡数据下是失效的指标**，此时应该看 F1-score、Recall 或 AUC 等指标，并在训练时使用类别权重或重采样。
  - **Recall（召回率 / 查全率）**：在所有真实属于少数类的样本里，模型成功识别出来的比例。用来衡量能不能把少数类样本找全。
  - **Precision（精确率 / 查准率）**：模型预测为少数类的样本中，真正是少数类的比例。衡量预测为少数类的结果靠不靠谱。
  - **F1-score**：精确率和召回率的调和平均，综合两者，兼顾查准和查全；F1 越高代表模型在少数类上综合表现越好。
  - **AUC**：描述模型区分正负样本的整体能力，不受类别不平衡影响。AUC 越接近 1，模型区分两类的能力越强。

- **如果想要过拟合这个数据集，你会怎么做？为什么？**
  做法：增加隐藏层大小（如 256）、增加层数、移除正则化、延长训练轮次。
  原因：过拟合就是让模型容量远大于数据复杂度，从而死记硬背。观察现象：Train Loss 持续下降，但 Val Loss 在中后期开始上升，两条曲线分叉。决策边界会变得极其扭曲，甚至把孤立的噪声点也包围进去。
